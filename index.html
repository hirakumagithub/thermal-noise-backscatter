熱雑音バックスキャッター通信（仕組みと理論）

ビット: 0 (端子整合・吸収)

1. 動作メカニズム

ビット「1」：全反射モード

送信アンテナ端子を短絡（ショート）または開放（オープン）に切り替えます。周囲から入射した環境熱雑音はアンテナで吸収されず、強力に反射波として受信機へ戻ります。

ビット「0」：整合・吸収モード

アンテナ端子に特性インピーダンスに等しい抵抗を接続（整合負荷）。熱雑音はアンテナに吸収され、受信機側への反射雑音電力が大幅に低下します。

2. 物理背景と数式

送信機自体は搬送波（電波）を一切出力しません。導体内の電子の揺らぎであるジョンソン・ナイキスト熱雑音の反射率を変調（バックスキャッター）します。

熱雑音電力（ジョンソン・ナイキストの式）： $$P_{\text{noise}} = k_B T B$$
  • \(k_B\)：ボルツマン定数 (\(1.38 \times 10^{-23} \, \text{J/K}\))
  • \(T\)：絶対温度 [K]（室温 \( \approx 300\,\text{K} \)）
  • \(B\)：受信帯域幅 [Hz]
反射係数 \(\Gamma\) による変調： $$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$
  • 整合時（ビット0）：\(Z_L = Z_0 \implies \Gamma = 0\)（無反射・吸収）
  • 短絡時（ビット1）：\(Z_L = 0 \implies \Gamma = -1\)（全反射）
  • 開放時（ビット1）：\(Z_L = \infty \implies \Gamma = +1\)（全反射）
通信路容量の上限（シャノンの定理と極符号）： $$C = B \log_2 \left(1 + \frac{\Delta P_{\text{reflected}}}{P_{\text{rx\_noise}}}\right)$$ スタンフォード大学のチームは、反射・吸収の微小な雑音電力差 \(\Delta P\) を正確に捉える数理モデルを導出。極符号（Polar Code）を適用することで、この理論限界に近い毎秒キロビット級の通信を達成しました。
